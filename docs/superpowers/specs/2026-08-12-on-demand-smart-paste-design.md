# Prompt 新建页按需智能粘贴设计

## 目标

删除智能粘贴成功后的常驻状态条，减少新建页重复信息和纵向占用，同时完整保留首页 `⌘V` 智能新建、字段解析、撤销及重新粘贴能力。

## 交互

- 空白新建页显示一行轻量入口：`从剪贴板智能填充  ⌘V`。
- 首页通过 `⌘V` 携带内容打开新建页，或用户在入口执行粘贴后，入口立即从表单中消失。
- 填充成功后显示约 4 秒的非阻塞提示：`已自动填充标题和 Prompt`，附带“撤销”操作。用户继续编辑不受影响。
- 提示消失后，撤销入口不再常驻；“重新粘贴”“查看原文”“撤销填充”“清除填充”统一放入页面右上角 `···` 菜单。
- 已有草稿执行重新粘贴时继续显示覆盖确认，不静默覆盖。
- 编辑 Prompt 页面不显示智能粘贴入口，保持当前不支持智能粘贴的规则。

## 布局

- 页面顺序保持：类型状态 → 智能粘贴入口（仅空白时）→ 标题 → Prompt。
- 删除原 `44pt` 常驻“已智能填充”条；填充后标题区域自然上移，不保留空白占位。
- 成功提示使用现有 Toast/轻提示视觉，不新增卡片、弹窗或固定高度区域。

## 数据与状态

- 保留 `PromptComposerPrefill`、解析结果、草稿快照和一次性 token，避免重复应用。
- 4 秒提示只是视觉状态，不影响未保存修改判断。
- 提示自动消失不删除撤销快照；用户仍可从 `···` 菜单撤销或清除。
- 创建、取消或关闭页面时清理本次智能粘贴会话状态，不写入剪贴板历史。

## 验收

- 空白新建页能主动粘贴，首页 `⌘V` 仍能直接打开并填充。
- 填充后常驻状态条完全消失，标题和 Prompt 直接展示。
- 成功提示约 4 秒后消失，期间“撤销”有效。
- `···` 菜单可重新粘贴、查看原文、撤销和清除。
- 已有草稿不会被重新粘贴静默覆盖。
- 智能识别类型、未保存提醒、创建保存结果保持不变。
