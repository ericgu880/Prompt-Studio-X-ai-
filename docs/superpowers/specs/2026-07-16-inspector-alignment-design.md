# 信息栏对齐优化设计

## 目标

统一主界面和沉浸式预览中的信息栏视觉基线：预览左右内容顶部对齐，主界面 Prompt 正文卡片左右留白对称。

## 预览顶部对齐

- 图片、视频和 Markdown 预览的右侧信息栏标题顶部，与左侧主要媒体或 Markdown 内容卡片顶部处于同一水平线。
- 复用左侧主内容现有的顶部边距指标，媒体和 Markdown 信息栏不再分别维护不同的顶部常量。
- 信息栏背景仍覆盖整个窗口高度，仅内部内容调整到对齐基线。

## Prompt 正文左右边距

- 以 Prompt 正文当前左侧 `14pt` 文本边距为基准，让可见右侧留白同样为 `14pt`。
- 当正文需要滚动时，为覆盖式滚动条单独预留右侧空间，避免滚动条侵占正文的右侧文本边距。
- 不滚动时继续使用现有对称文本边距和高度测量规则。

## 不修改

- 页面级关闭按钮继续保持当前尺寸、交互和 `24pt` 顶部/右侧边距。
- 缩略图轨道的位置、`82pt` 宽度和显示规则保持不变。
- 信息栏宽度继续继承主界面实际宽度。
- Prompt 操作区、正文排版、媒体缩放、复制和编辑逻辑保持不变。

## 验证

- 增加 UI 布局回归检查，确保媒体与 Markdown 信息栏共用顶部对齐指标。
- 增加滚动 Prompt 正文回归检查，确保覆盖式滚动条拥有独立右侧预留空间。
- Swift Debug 构建、核心测试、Smoke Test、发布 UI 检查通过。
- 手动检查主界面长 Prompt 的左右可见留白，并打开图片、视频和 Markdown 预览检查顶部误差不超过 `1pt`。
