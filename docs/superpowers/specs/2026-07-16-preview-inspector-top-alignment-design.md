# 预览内容与信息栏顶部对齐设计

## 目标

在图片、视频和 Markdown 沉浸式预览中，让右侧信息栏的标题内容顶部与左侧主要预览内容卡片顶部处于同一水平线，形成稳定的横向视觉基线。

## 范围

- 图片与视频预览的信息栏标题区域。
- Markdown 预览的信息栏标题区域。
- 左侧对齐基准为主要媒体或 Markdown 内容卡片经过现有垂直边距后的顶部。

## 不修改

- 页面级关闭按钮继续保持当前尺寸、交互和 `24pt` 顶部/右侧边距。
- 缩略图轨道的位置、宽度和显示规则保持不变。
- 信息栏宽度继续继承主界面实际宽度。
- Prompt 操作区、正文排版、媒体缩放和编辑逻辑保持不变。

## 实现原则

- 提取或复用预览主内容现有的顶部边距指标，作为信息栏内容区域的顶部边距来源。
- 媒体和 Markdown 预览共享同一对齐规则，避免分别维护视觉常量。
- 信息栏背景仍覆盖整个窗口高度，仅内部标题内容下移到对齐基线；关闭按钮仍独立固定在窗口右上角。

## 验证

- 增加 UI 布局回归检查，确保媒体与 Markdown 信息栏共用顶部对齐指标。
- Swift Debug 构建、核心测试、Smoke Test、发布 UI 检查通过。
- 手动打开图片、视频和 Markdown 预览，检查左右内容顶部误差不超过 `1pt`，并确认关闭按钮位置未变化。
